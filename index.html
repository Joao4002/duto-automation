Projeto em Destaque

Simulador de RF para Treinamento — desenvolvido para o Mercado Livre

A Duto Automation desenvolveu, como prestação de serviço, um simulador de coletor RF (rádio frequência) para treinamento de colaboradores, reproduzindo o fluxo operacional de Armazenamento / Armazenar para Venda.

A aplicação foi construída como uma PWA (Progressive Web App) que simula a operação real de um dispositivo RF: login de treinamento, leitura de MU/caixa, endereço, produtos e posições, até a confirmação e conclusão do fluxo — permitindo que colaboradores pratiquem o processo antes de operar o dispositivo real.

Projeto desenvolvido pela Duto Automation como prestação de serviço.
